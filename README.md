# Podcast Page

A responsive podcast browsing web page built with HTML, CSS, and Bootstrap. Users can explore multiple podcast channels and view their individual episodes — all within a clean, single-page experience.

## Preview

The home page displays a grid of podcast channels. Clicking any card navigates to that podcast's episode list, where a **Back** button returns to the home screen.

## Features

- Browse 4 podcast channels: **Puri Jagannadh**, **TEDx Talks**, **Sadhguru**, and **On Purpose with Jay Shetty**
- Each channel shows a list of episodes with title, description, and duration
- Single-page navigation — no page reloads
- Responsive layout using Bootstrap 4 Flexbox

## Tech Stack

| Technology | Purpose |
|---|---|
| HTML5 | Page structure and content |
| CSS3 | Custom styling |
| Bootstrap 4.5 | Responsive grid and layout utilities |
| jQuery 3.5 | DOM manipulation for section switching |

## Project Structure

```
podcast-page/
├── index.html    # Main HTML file with all podcast sections

```

## Getting Started

No installation or build step needed — this is a pure front-end project.

1. Clone the repository:
   ```bash
   git clone https://github.com/Anandu-12233/podcast-page.git
   ```
2. Open `index.html` in any web browser.

That's it!
